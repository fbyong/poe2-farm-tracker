# PoE 2 Farm Tracker

I built this tool to make it easier to track my farming sessions in **Path of Exile 2**. It runs entirely in your browser and lets you keep track of Div/h, loot, presets, hotkeys, and more — no installation or account required.

## ✨ Features

- **Integrated Timer** — Track your farming sessions with automatic **Divines per Hour (Div/h)** calculation.
- **Farming Presets** — Create different presets for your favorite farming strategies.
- **Combined Overview** — See the total loot and profit across all your presets.
- **Loot Tracking** — Add, edit, reorder (drag & drop), and price your drops however you want.
- **Custom Hotkeys** — Set up shortcuts to speed up counting and timer controls.
- **Discord Summary** — Copy a nicely formatted summary to share with friends.
- **Import & Export** — Back up or restore all your data with a single `.json` file.
- **Customizable Layout** — Resize the UI, switch layouts, and adjust window opacity.

## 🚀 Getting Started

### Use it online

1. Open the Live Demo.
2. Create your first preset.
3. Start tracking your runs.

### Or run it locally

1. Download the latest HTML file from the **Releases** page.
2. Open it in any modern browser.
3. That's it — your data is saved locally in your browser.
